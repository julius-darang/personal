Power Systems

Philippine Power Grid Visualization

Go →

A public web app that visualizes the Philippine power grid — the Visayas transmission backbone (69 / 138 / 230 kV) plus per-province distribution — with a pandapower load-flow model running underneath. Real NGCP topology isn't public, so the build combines OSM, a hand-curated dataset of NGCP substations, and flagged synthetic infill. Phase 1 (data foundation) is done: 2,960 buses and 2,967 lines, with the Visayas peak load landing within 4% of published figures.

Power Systems

Visayas Grid — Live Prototype

Go →

A lightweight, Vercel-only prototype that visualizes and models the Visayas transmission grid (69 / 138 / 230 kV plus the 350 kV HVDC link) from real, publicly available NGCP data. Data is precomputed into static JSON and served from the CDN — no backend or database. A Leaflet map encodes voltage and line loading by color with click-to-inspect bus and line panels, and a pandapower load-flow snapshot runs behind a topology-validation gate.

Python pandapower Leaflet JavaScript Vercel
