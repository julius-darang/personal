Visayas Grid

An interactive map and pandapower load-flow model of the Philippine Visayas transmission grid — built as a deliberately lightweight, backend-free prototype.

Live demo → GitHub →
54 buses 60 lines 115 generator units AC load flow No backend Deployed on Vercel

The problem

The Visayas is an island grid — generation and load spread across Cebu, Negros, Panay, Leyte, Samar, Bohol and more, stitched together by submarine cables and a single HVDC link to Luzon. NGCP's actual network data isn't published in a form you can model, and the "proper" way to build a tool like this — my earlier v2 design with PostGIS, a FastAPI backend, and Docker on a cloud VM — was 10–11 weeks of infrastructure before the first useful pixel. I wanted a working, public, modelled map in a fraction of that.

The approach

So I inverted the architecture: do all the heavy computation offline, and ship nothing but static files. A Python pipeline cleans an NGCP-coded dataset down to the Visayas (54 buses, 60 lines, 115 generator units), runs a pandapower AC load flow, and writes the results to GeoJSON. A React + Leaflet frontend reads those files directly. There is no backend at runtime — Vercel's CDN serves pre-baked JSON, which keeps the whole thing fast, free, and almost nothing to operate.

What it does

  • Renders the transmission network on a dark map, color-coded by nominal voltage (350 / 230 / 138 / 69 kV) and by line loading from the load-flow result
  • Click any bus or line to inspect its modelled values
  • Filter by island and by voltage level
  • Summarises demand against generation for the current view
  • A provenance footer and "About" panel state exactly what is measured versus estimated

The result

It's live, unit-tested with Vitest, and — importantly — honest about its data. Submarine cables use IEC 60840 XLPE parameters instead of guesses; loads that NGCP doesn't expose are gap-filled from clearly flagged estimates; and every modeling constant lives in one file with a source citation. The prototype is built so fuller real data can be swapped in without touching the frontend. The heavier, full-stack version of this idea lives in its sibling project, powergrid.
